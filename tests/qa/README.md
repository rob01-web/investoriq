# InvestorIQ QA Authority

`node tests/qa/run-all.js` (or `npm run qa`) is the single canonical **local launch-regression runner**.

It is supporting evidence only. It has zero constitutional authority and is not production or launch certification. InvestorIQ architecture and product doctrine own the system; tests follow them.

Package-script taxonomy:

- `qa` — canonical local launch-regression runner.
- `qa:component:*` — focused component/regression suites; supporting evidence only.
- `qa:diagnostic:*` — historical, RETEST-specific, institutional/experimental, or future-product diagnostics; never launch authority.
- `qa:utility:*` — local QA utilities.

Premium is future-only and OFF. Historical Acquisition Memo / `ic` tests and helpers may be retained only as clearly non-authoritative diagnostics or legacy implementation fixtures. Current launch products are Screening and Full Underwriting.
